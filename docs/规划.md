# 软件指南生成器（桌面版）规划

把 `~/.agents/skills/software-manual-generator` 的流程做成一个 macOS 桌面 App。旧 skill 和 `~/Desktop/软件指南生成` 里的历史项目只读，不修改。

## 1. 边界

- 流程由软件固定，大模型只在每一步里按 JSON 契约生成内容。
- 交付模板不变：版式常量、封面结构、文件命名、代码文档格式都从旧 skill 原样复制。唯一的版式改动是修 bug：截图表格行加 `cantSplit`，防止「图1」图注单独掉到下一页。
- **代码文档**：每个项目通过「代码来源」指定一个文件夹或文件，软件按原格式排版。软件里不内置任何代码正文。没有代码来源时不生成代码文档，并明确提示。不提供改写、混淆或用大模型生成代码的功能。
- **TXT**：环境字段（开发硬件、操作系统、开发工具等）沿用旧模板的值，作为可修改的默认值。`【源程序量】` 按代码来源的实际行数统计，不再写死。
- **截图**：界面里不得出现软件名、App 名、版本号或名称型 logo。出现即判失败，重新生成。
- **密钥**：用 Electron `safeStorage`（系统钥匙串加密）保存，不写进项目目录。

## 2. 技术选型

| 部分 | 选型 | 理由 |
|---|---|---|
| 桌面壳 | Electron 43.4.0 | 和四季画布同一版本，本机已有缓存；主进程是 Node，可以直接复用模板脚本 |
| 界面 | React 19 + Vite + antd 6 | 和四季画布一致 |
| 核心逻辑 | `core/`，纯 Node ESM | 不依赖 Electron，用 `node --test` 直接测试 |
| 网络 | `fetch` + `AbortController` | 真正的异步并发，不用 `spawnSync(curl)` |
| 模板脚本 | `core/templates/`，从旧 skill 复制 | 用 `ELECTRON_RUN_AS_NODE` 子进程运行 |
| 存储 | 应用数据目录下的 JSON 文件 + 只追加的 JSONL 调用记录 | 原子写入（先写临时文件再改名） |

## 3. 生图网关（参考四季画布）

**线路类型**
- **同步**（OpenAI 兼容 / CPA）：一个请求等到出图。
- **异步任务**（APIMart）：提交后拿到任务号，再轮询结果。
- **声明式自定义**：接口路径、请求体、结果路径都写在 JSON 里，加新中转不用改代码。

**尺寸**
- 目标 864x1824，即 9:19。
- 收像素的线路直接发像素尺寸。
- 只收比例的线路，选最接近的比例（APIMart 选 1:2）。
- 如果线路报错说不支持像素尺寸，从报错里解析出允许的比例列表，自动改用比例并立即重试。

**并发**
- 每屏一个独立任务，同时发出。取消 screen-01 先单独生成的等待。
- 每条线路有自己的并发上限，另有全局上限。
- 一屏失败不影响其他屏。不会再出现「一张失败、整批作废重买」。

**超时补发（对冲）**
- 补发线 = 该线路最近 50 次成功耗时的第 85 百分位，限制在 20–120 秒之间。没有历史数据时用每条线路的默认值。
- 超过补发线就向另一条线路补发同一屏。优先选同模型、不同上游的线路。是否允许换模型补发由开关控制。
- 先返回且图片有效的一边胜出。同步线路的另一边直接取消；异步线路的另一边继续在后台查询，出图后存为「备选图」，钱不会白花，可以一键替换。
- 每批补发次数有上限，可以设为 0 关闭。

**失败处理**

| 情况 | 处理 |
|---|---|
| 模型不存在 / 鉴权失败 / 参数错误 | 标为「配置错误」，停用这条线路，测试通过后恢复 |
| 429 / 额度用完 | 按 Retry-After 或报错里的剩余时间冷却；解析不出时冷却 15 分钟 |
| 5xx / 网络错误 | 2–5 秒后同一线路重试 1 次，再换下一条 |
| 连续失败 3 次 | 熔断 5 分钟 |

**任务账本（参考四季画布）**
- 异步任务号一拿到就落盘。软件重启后继续查询，不重复提交，避免重复扣费。
- 提交途中崩溃、没拿到任务号的，标为「提交结果未知（可能已扣费）」，由你决定是否重试。
- 查询超时不算失败，保留任务号以后继续查。

**记录**
- 每次调用写一行：屏、线路、模型、请求尺寸、实发尺寸、是否补发、是否胜出、耗时、HTTP 状态码、错误类型。
- 统计页按线路显示 P50 / P90 耗时和成功率。

## 4. 大模型

- 支持 OpenAI、DeepSeek、智谱以及任意 OpenAI 兼容接口（包括 CPA）。可以拉取模型列表。
- 每个步骤单独指定模型：规划、文案、设计说明用文字模型；截图验收、截图对账用看图模型。
- DeepSeek 没有看图模型，看图步骤可选 OpenAI 或智谱 GLM-V。没有配看图模型时，改为人工逐张确认。

## 5. 固定流水线

| 步骤 | 谁做 | 产出 |
|---|---|---|
| S1 规划 | 文字模型 | software-profile / feature-map / screen-plan / ui-contract + 品牌禁词 |
| S2 提示词 | 程序 | prompts/screen-NN.md（品牌禁令块由程序追加，不可编辑） |
| S3 生图 | 网关 | screens/screen-NN.png |
| S4 品牌硬门 | 看图模型 + 程序禁词匹配，或人工确认 | 每屏验收结果，失败自动重生（每屏最多 3 次） |
| S5 文案 | 文字模型起草，再由看图模型按截图对账 | content.json |
| S6 设计说明（可选） | 文字模型 | design.sections |
| S7 回执 | 程序 | 按当前 PNG 自动计算 SHA-256 回执 |
| S8 构建 | 模板脚本 | 交付包 + manifest + region-index，校验通过后再替换旧交付包（旧的先归档） |

每一步记录输入哈希，只重跑受影响的步骤。支持的编辑操作：单屏重生、换成备选图、改文案、改软件名、加设计说明。

## 6. 项目与批量

- **工作区**：默认 `~/Desktop/软件指南生成`，可以改。
- **导入历史项目**：原地登记，不复制（目录共 7.6G）。按状态分级：
  - 可直接编辑
  - 待硬门（回执缺失或和当前截图对不上）
  - 只读（没有 content.json）
- 历史生图记录导入为测速初始数据。
- **批量**：表单或 CSV 新建多个项目，排队运行，项目并发数可调。软件重启后自动续跑。

## 7. 验证

- `core/` 单元测试，用本地模拟中转覆盖：同步、异步、补发、失败切换、冷却、重启续查。
- 端到端：假大模型 + 模拟中转 → 生成完整交付包 → LibreOffice 转出 PDF → 校验通过。
- 启动桌面 App 截图检查各页面。
